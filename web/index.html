    Settings, pronunciation & sessions

    Copy your settings as one line of text, or save them as settings.txt next to the app files in the shared folder — the page loads that file automatically on every launch, on any computer. Pronunciation fixes live in the dict part, for example "dict":{"Dr.":"Doctor","kubectl":"kube control"}; they change only how words are spoken, never your text. A session file saves the draft, flags, and settings together.

    ● autosaving to this drive
    Portable voices work offline. With the built-in browser voices, text stays in this tab and generated audio stays in memory until export. If you explicitly enable local CosyVoice GGUF, selected sentences are sent only to its separately running process at 127.0.0.1 on this computer; starting that process with -m auto may download missing model weights. No cloud speech server is used by this edition.
    Keyboard and troubleshooting

    New to Read Aloud? The user guide walks through everything on one friendly page — it also lives on the drive as HOW TO USE.html.

    F8 reads aloud from the cursor to the end of the draft, highlighting each sentence as it is spoken. The next sentence is prepared while the current one plays, so reading is continuous. With text selected, F8 reads only the selection. Esc stops and leaves a ▸ resume marker on the sentence — it follows the sentence through edits and clears itself once you read it again. Pressing F8 resumes from the stopped sentence. Editing the text stops playback. Press ? anytime for the shortcut overlay.

    Adding voices: copy a compatible voice package folder into the voices folder next to shared on this drive, then relaunch. Three families work: Piper VITS packages hold voice.json, model.onnx and tokens.txt; KittenTTS and Kokoro packages also include their matching voices.bin and carry several speakers in one file. Multi-speaker Piper models (such as LibriTTS-R with 904 speakers) work too — the Speaker dropdown appears automatically, and a curated speakers list in voice.json (schemaVersion 2) gives your favorites proper names. It will appear in the Voice dropdown automatically. The voice package maker can build and test compatible Piper, KittenTTS, and Kokoro packages. Invalid packages are skipped and reported without affecting working voices.

    F7 replays the current sentence (or, while stopped, reads the sentence at the cursor once). F9 flags the current sentence for later without interrupting playback; F10 jumps to the next flagged sentence. Show opens the flag panel: click any entry to jump to it, and flags follow their sentences through edits and moves — a rewritten sentence keeps its flag, and a deleted one is listed as not found. Flagged sentences carry a dotted underline in the text. Step waits after each sentence — press F8 (or Space outside the text box) for the next one. Focus dims everything except the sentence being spoken.

    Render / Update synthesizes every sentence of the draft into memory, and Export WAV stitches them into one audio file with natural pauses. After editing, Render / Update re-records only the sentences that changed; everything else is reused instantly. Changing the speed re-renders everything, since it produces different audio.

    Do not open shared/index.html directly. Close this page and use the matching START launcher in the parent folder. Keep the shared folder beside the launcher.
